# USA Housing Price Prediction

A Data Science and Machine Learning project that explores housing data and predicts house prices using Python and Linear Regression.

## Project Overview

This project demonstrates a basic machine learning workflow using the USA Housing dataset. It includes data exploration, preprocessing, visualization, model training, and evaluation.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

- Loaded and explored the USA Housing dataset.
- Performed data inspection and preprocessing.
- Visualized feature relationships and correlations.
- Split the dataset into training and testing sets.
- Trained a Linear Regression model.
- Evaluated the model using R² Score, Mean Absolute Error (MAE), and Mean Squared Error (MSE).

## Machine Learning Model

**Linear Regression**

The model was trained to predict housing prices based on the available numerical features in the dataset.

## Project Files

- `USA_Housing_Prediction.ipynb` – Jupyter Notebook containing the project code, analysis, visualizations, and model evaluation.

## How to Run

1. Open the notebook in Google Colab.
2. Upload or load the required USA Housing dataset.
3. Run the notebook cells sequentially.
